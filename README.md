# Personal Portfolio

A two-page personal portfolio website written in plain HTML for the Internet Programming I course (Chapter 2, Part I).

**Author:** Gurmesa Borana
**University:** Addis Ababa Science and Technology University
**Department:** Software Engineering

## Pages

- `index.html` is the home page with About, Skills, Projects, Education and Contact sections.
- `projects.html` is the projects page with a summary table and details of each project.

## HTML topics used

- Document structure, headings, paragraphs, line breaks and rules
- Text formatting, quotations and code blocks
- Hyperlinks (relative, absolute, email, phone and download)
- Images, image map and favicon
- Lists (unordered, ordered, description and nested)
- Tables with rowspan, colspan, caption, header and footer

## How to view

Open `index.html` in any web browser.
